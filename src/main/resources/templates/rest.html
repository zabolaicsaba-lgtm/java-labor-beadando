Végpontok

Az olvasás bejelentkezés nélkül működik. Létrehozáshoz, módosításhoz és törléshez ADMIN felhasználó HTTP Basic azonosítása kell. A válaszok a települést és a megyét is tartalmazzák.

  • GET – az összes széltoronyrekord.
  • GET – egy rekord azonosító alapján.
  • POST – új rekord (JSON: darab, teljesitmeny, kezdev, helyszinId); válasz: 201 és Location fejléc. ADMIN.
  • PUT – rekord módosítása, ugyanazzal a JSON-nal. ADMIN.
  • DELETE – rekord törlése; válasz: 204. ADMIN.

Nem létező azonosító esetén a válasz HTTP 404, hibás adatnál 400, hiányzó bejelentkezésnél 401, USER szerepkörnél 403. Kikapcsolt adatbázis-profil esetén a végpontok HTTP 503 választ adnak.
