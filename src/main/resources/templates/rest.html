Végpontok

Az API bejelentkezés nélkül, kizárólag olvasásra használható. A válaszok a települést és a megyét is tartalmazzák.

  • GET – az összes széltoronyrekord.
  • GET – egy rekord azonosító alapján; az 1 helyére más azonosító is írható.

Nem létező azonosító esetén a válasz HTTP 404. Kikapcsolt adatbázis-profil esetén a végpontok HTTP 503 választ adnak.
